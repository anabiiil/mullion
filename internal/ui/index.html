Frontend

Managed dev servers & production builds

Mullion runs npm run dev for you behind the domain — switch a domain to build to serve the last production build instead (it builds first when needed). Dev servers wake automatically when you open their link. They sleep after 2 minutes with no open tab, or after 10 minutes with a tab open but no activity (requests or code edits).

Mullion Terminal is your terminal — project “Terminal” buttons open there. This built-in terminal still works here.

HTTPS certificates

Every https:// site is signed by Mullion's local certificate authority. Trusting it once makes browsers show the padlock. Firefox, phones and VMs keep their own trust store — export the certificate and import it there.

Wildcard DNS

Only needed for a site's * (every-subdomain) alias, e.g. anything.shop.test — named aliases like api.shop.test work through the hosts file without it. Turning it on installs a small OS resolver hookup once, which asks for administrator rights.

Domain suffix

Current TLD .test
Change to

Every linked site's domain changes at once — e.g. myapp.test → myapp.local. Avoid real public TLDs like .dev or .app: browsers force them to HTTPS, which breaks plain-HTTP local sites.
