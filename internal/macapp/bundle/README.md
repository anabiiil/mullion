# bundle/

`Mullion.app.tar.gz` belongs here — a gzipped tar of the native macOS
app, with `Mullion.app/` as its top-level entry. It's generated by
running:

    bash macapp/build.sh

from the repo root, and it's gitignored: this placeholder is the only
file committed in this directory, so `//go:embed bundle` always has a
match and `go build`/`go test` work on checkouts (and non-mac builds)
that haven't run the build script. Without the tarball, `macapp.Available()`
reports false and installing the app is silently skipped.
