Your whole local dev stack, one binary.

Mullion serves PHP and Node projects on .test domains with trusted HTTPS. It also manages PHP, Node, MySQL, PostgreSQL and MongoDB, with a panel for every project. It runs on macOS and Windows, with no Docker or config files.

Project page

Run commands with live output

The Commands tab lists the project's artisan or bin/console commands, npm scripts and Composer scripts. Commands run with the project's own PHP and Node, and the output streams in live.

  • Quick actions and favorites
  • Interactive commands go to a terminal tab
  • mullion run shop -- php artisan migrate from a shell

Install

Up and running in one command

mullion setup installs Caddy, the latest PHP, Composer, Node LTS and MySQL with phpMyAdmin, and trusts the local certificate. Re-running it is always safe.

$ brew tap anabiiil/tap
$ brew trust anabiiil/tap
$ brew install mullion
$ mullion setup

Without Homebrew: curl -fsSL https://raw.githubusercontent.com/anabiiil/mullion/main/install.sh | sh. Setup installs Mullion.app into Applications.

> scoop bucket add mullion https://github.com/anabiiil/scoop-bucket
> scoop install mullion
> mullion setup

Or download mullion.exe from Releases and double-click it. Setup asks for administrator rights once.

Link your first project

cd ~/code/shop && mullion link --secure → https://shop.test
